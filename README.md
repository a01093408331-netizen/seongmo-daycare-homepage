# 성모영아전담어린이집 공식 홈페이지

> 작은 아이의 오늘을 소중히, 행복한 내일을 함께 준비합니다.

만 0세 ~ 만 2세 영아전담 어린이집 공식 홈페이지입니다.
**설치할 프로그램 없이** 파일만 열면 바로 확인할 수 있고, 수정도 쉽게 할 수 있게 만들었습니다.

---

## 1. 홈페이지 보는 방법

### 가장 쉬운 방법
`index.html` 파일을 **더블클릭** 하세요. 인터넷 창이 열리며 홈페이지가 보입니다.

### 인터넷에 무료로 올리는 방법 (GitHub Pages)
1. GitHub 저장소 페이지 접속
2. 상단 **Settings** 클릭
3. 왼쪽 메뉴 **Pages** 클릭
4. `Source` 를 **Deploy from a branch** 로 선택
5. `Branch` 를 `main` (또는 현재 브랜치), 폴더는 `/ (root)` 선택 후 **Save**
6. 1~2분 뒤 나오는 주소가 우리 어린이집 홈페이지 주소입니다


## 3. 사진 넣는 방법 ⭐ 가장 많이 쓰는 기능

**코드는 건드리지 않으셔도 됩니다.** 두 단계면 끝납니다.

1. 사진 파일 이름을 아래 표의 이름으로 바꿉니다. (예: `우리원사진1.jpg` → `hero-main.jpg`)
2. `assets/img/` 폴더에 그대로 넣습니다.

끝입니다. 홈페이지가 알아서 사진을 찾아 보여줍니다.

- 확장자는 **`.jpg` 또는 `.png`** 둘 다 됩니다.
- **한 번에 다 안 넣으셔도 됩니다.** 넣은 자리만 사진으로 바뀌고, 안 넣은 자리는 지금의 임시 그림이 그대로 남습니다.
- 기존 `.svg` 파일은 **지우지 마세요.** 사진이 없을 때 대신 보여주는 그림입니다.

> `assets/img/사진넣는방법.txt` 에도 같은 안내가 들어 있습니다. 사진 폴더를 열면 바로 보입니다.

## 6. 글자 내용 바꾸는 방법

`<!-- 이렇게 생긴 부분 -->` 은 설명글이라 화면에 보이지 않습니다. 지우지 않으셔도 됩니다.

```html
<!-- ===================== 2. 우리 원의 장점 ===================== -->
```

## 7. 색상 바꾸는 방법

`assets/css/style.css` 파일 맨 위 `:root { ... }` 부분의 색상만 바꾸면
홈페이지 전체 색이 한 번에 바뀝니다.

```css
--primary:  #EE8B70;   /* 메인 색 (소프트 코랄) */
--sage:     #7FB79B;   /* 보조 색 (세이지 그린) */
--sky:      #86BBE0;   /* 포인트 색 (스카이 블루) */
```

## 10. 상담 신청 폼 안내

지금은 **별도 서버 없이** 동작하도록, 신청 버튼을 누르면
작성한 내용이 담긴 **메일 쓰기 창이 자동으로 열리는 방식**입니다.

> 나중에 신청 내용을 자동으로 저장하고 싶으시면
> 구글 폼 연동이나 별도 서비스 연결이 필요합니다. 요청해 주시면 추가해 드릴 수 있습니다.

**블로그에 글을 올리시면 홈페이지 「가정과의 소통」 아래 "우리 원 최신 소식"에 자동으로 나타납니다.**
원장님이 따로 하실 일은 없습니다. 평소처럼 블로그에 글만 올리시면 됩니다.

### 어떻게 동작하나요

GitHub 이 **30분마다** 블로그를 확인해서 새 글을 홈페이지로 가져옵니다.
글 제목·날짜·사진·요약이 카드 모양으로 표시되고, 누르면 블로그 글로 이동합니다.

- 글을 올리고 **최대 30분 정도** 뒤에 반영됩니다 (GitHub 사정으로 조금 더 걸릴 수 있습니다)
- 최신 글 **6개**까지 보여줍니다
- 블로그에 글이 없거나 일시적으로 접속이 안 되면, 이 영역은 **조용히 숨겨집니다** (홈페이지가 깨지지 않습니다)

### 지금 바로 반영하고 싶을 때

1. GitHub 저장소 상단 **Actions** 탭 클릭
2. 왼쪽에서 **"블로그 새 글 가져오기"** 선택
3. 오른쪽 **Run workflow** 버튼 클릭 → 1분 뒤 반영됩니다

### 처음 한 번만 확인해 주세요

저장소를 업로드한 뒤 **Settings → Actions → General** 에서
`Workflow permissions` 가 **Read and write permissions** 로 되어 있는지 확인해 주세요.
(안 되어 있으면 자동 반영이 동작하지 않습니다)

## 12. 인스타그램 최신 게시물 ⭐ 연동 완료

**인스타그램에 게시물을 올리시면 홈페이지 「가정과의 소통」 아래 "인스타그램 소식"에 자동으로 나타납니다.**
LightWidget 이라는 서비스를 통해 연결되어 있으며, 원장님이 하실 일은 없습니다.

- 게시물을 올린 뒤 **30분 정도** 뒤에 반영됩니다
- 위젯이 일시적으로 안 뜨면 **"인스타그램 바로가기" 안내가 대신 표시**되어 화면이 비지 않습니다

### 위젯 모양을 바꾸고 싶을 때

1. `lightwidget.com` 로그인 → 내 위젯 → 설정 변경 → 저장
2. 새로 나온 코드에서 `<iframe src="...">` 주소만 복사
3. `index.html` 에서 `lightwidget.com/widgets/` 를 찾아 그 주소를 교체

### 위젯을 아예 빼고 싶을 때

`index.html` 에서 `<div class="insta reveal">` 부터 그 짝이 되는 `</div>` 까지 지우면 됩니다.
어려우시면 말씀해 주세요.
